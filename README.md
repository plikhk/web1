## Description

A small multi-page website with the HTML & CSS tasks from Assignment 1.
Every page has the same navigation bar at the top, so it is easy to move between the tasks.

| Task | Page | What is inside |
| --- | --- | --- |
| Task 1 | `index.html` | Personal page with a profile card, headings, paragraphs, ordered and unordered lists, image and links |
| Task 2 | `task2/index.html` | Layout made only with `div`, `float` and positioning: header, navbar, left sidebar, right content, footer |
| Task 3 | `exercise1/index.html` | Tribute page about Grace Hopper with two Google Fonts, a portrait, lists and a "Learn more" button |
| Task 4 | `task4/index.html` | Styled table with student grades (rowspan and colspan) and a styled feedback form |

Task 5 (midterm project topic and wireframe) is a group task and is not part of this repository.

## How to run

1. Download or clone the repository.
2. Open `index.html` in any browser.
3. Use the navigation bar to open the other pages.

No installation is needed. The tribute page loads fonts from Google Fonts and the portrait from Wikimedia Commons, so it needs an internet connection to look exactly as intended.

## How it is published

The site is published with GitHub Pages: repository **Settings, Pages, Deploy from a branch, `main` / root**.
